# REWIND RAMPAGE
## 第三幕技术设计文档 — THE ARCHIVE

**版本：** Act III v1.0  
**引擎：** Unity / C#  
**游戏时间：** 90 秒倒计时  
**开始时间：** 01:30  
**结束时间：** 00:00  
**调试要求：** 可独立运行，无需完成第一幕和第二幕

---

## 1. 关卡概述

第三幕为游戏最终关卡。

玩家进入时间档案空间，面对多个与自己外形相同的时间残影（Echo）。

这些 Echo 不再按照历史录像回放，而是由 AI 实时随机移动、生成倒带路径并发动攻击。

玩家需要利用已有的倒带冲刺与轨迹交叉爆炸机制，在敌人的倒带攻击中生存，并在最后阶段摧毁时间核心。

### 胜利条件

同时满足以下两个条件：

1. 玩家在倒计时结束时仍然存活。
2. 最终时间核心已被摧毁。

当倒计时达到 `00:00` 时统一判定胜利或失败。

若玩家生命值提前归零，则立即判定失败。

**摧毁核心不会提前结束第三幕。**

---

## 2. 时间与阶段设计

第三幕独立使用一个 90 秒倒计时计时器。

| 剩余时间 | 阶段 | 场上 Echo 上限 | 主要机制 |
|---|---|---|---|
| 1:30–1:00 | 第一阶段：觉醒 | 2 | 敌人随机移动并发动倒带攻击 |
| 1:00–0:30 | 第二阶段：围猎 | 3 | 更频繁的随机倒带，多条轨迹交叉 |
| 0:30–0:00 | 第三阶段：崩溃 | 4 | 时间核心出现，敌人持续攻击 |
| 0:00 | 结算 | — | 根据玩家存活和核心状态判定结果 |

计时器采用 `Time.deltaTime` 更新，始终显示 `MM:SS`。

时间耗尽后停止敌人 AI、攻击生成及玩家输入，进入结算状态。

## 3. Echo 敌人系统

### 3.1 基本要求

所有 Echo 使用与玩家相同的角色外观，但使用不同颜色、透明度或残影特效进行区分。

Echo 必须具备以下行为：

- 在场景中随机移动。
- 随机选择倒带攻击时机。
- 生成用于倒带的随机轨迹。
- 沿轨迹高速倒退并对玩家造成伤害。
- 攻击前显示轨迹预警。
- 攻击结束后短暂硬直。
- 可被玩家的倒带冲刺及交叉节点爆炸击败。

Echo 不依赖真实玩家历史记录。

### 3.2 AI 状态机

| 状态 | 行为 | 退出条件 |
|---|---|---|
| SPAWN | 生成并播放出现动画 | 动画结束 |
| WANDER | 随机移动，寻找攻击机会 | 攻击计时器结束 |
| WARNING | 生成随机倒带轨迹并显示危险区域 | 预警计时结束 |
| REWIND | 沿生成轨迹高速倒退并执行伤害判定 | 轨迹执行完成 |
| RECOVERY | 进入短暂硬直 | 硬直计时结束 |
| DEAD | 播放死亡效果，移除敌人 | 清理完成 |

正常行为循环为：

`SPAWN → WANDER → WARNING → REWIND → RECOVERY → WANDER`

### 3.3 随机倒带轨迹

为了避免历史记录长度不足，Echo 的倒带路径完全由程序生成。

每次准备倒带时：

1. 获取 Echo 当前位置。
2. 获取玩家当前位置，允许加入少量随机预测偏移。
3. 在两者之间生成随机弯曲路径。
4. 将路径组织成一段虚构的历史轨迹，其终点为 Echo 当前所在位置。
5. 显示这条路径作为攻击预警。
6. 倒带开始后，Echo 按照轨迹采样点的逆序高速移动，最终冲向预先锁定的目标区域。
7. 对路径经过的玩家进行碰撞与伤害判定。

可使用 Bézier 曲线或 Catmull-Rom 曲线生成路径。

**攻击路径必须在预警开始时锁定，不能在攻击过程中重新随机生成或实时追踪玩家。**

这样玩家能根据显示的危险轨迹进行躲避。

### 3.4 攻击随机性

| 参数 | 第一阶段 | 第二阶段 | 第三阶段 |
|---|---|---|---|
| Echo 攻击间隔 | 3–5 秒 | 2–4 秒 | 1.5–3 秒 |
| 攻击预警时长 | 0.7 秒 | 0.6 秒 | 0.5 秒 |
| 倒带持续时间 | 0.5 秒 | 0.45 秒 | 0.4 秒 |
| 同时倒带的敌人上限 | 1 | 2 | 2 |
| 攻击后硬直 | 1.0 秒 | 0.8 秒 | 0.6 秒 |

攻击时机、轨迹曲率和目标偏移均随机。

同时攻击数量由全局调度器限制，避免多个敌人无预警地覆盖全部活动空间。

### 3.5 敌人死亡与补充

Echo 可被玩家正常击败。

当当前存活数量低于该阶段要求的敌人数量时，在随机安全出生点补充 Echo。

补充生成应有短暂间隔，并避开玩家周围的近距离范围，防止敌人突然出生在玩家身上。

每个 Echo 独立生成自己的行为参数与攻击轨迹。

## 4. 玩家能力与伤害规则

第三幕复用前两幕已有的玩家控制与战斗系统。

包括：

- 正常移动。
- 玩家倒带冲刺。
- 倒带路径上的攻击判定。
- 历史轨迹交叉节点爆炸。
- 玩家生命值、受击反馈与无敌帧。

Echo 的倒带轨迹是危险区域。

只有在 Echo 正式进入 `REWIND` 状态后，轨迹才具有伤害判定；预警阶段不造成伤害。

同一个 Echo 的一次倒带攻击最多对玩家造成一次伤害，防止高速穿越时多次触发碰撞。

玩家倒带与 Echo 倒带的伤害规则可以共用轨迹碰撞模块，但敌人攻击不得修改玩家自身的历史轨迹缓存。

## 5. 时间核心系统

### 5.1 激活

当剩余时间首次达到 `00:30` 时，时间核心在场景中央或预设位置出现。

无需满足额外击杀数量要求，避免玩家因敌人随机行为无法进入最终阶段。

### 5.2 核心机制

时间核心初始拥有 3 点耐久。

玩家需要通过自身倒带冲刺或轨迹交叉爆炸攻击核心。

每次有效命中降低 1 点耐久，并播放全屏冲击效果。

为防止一次攻击持续多帧而重复扣血，同一次攻击事件只能对核心生效一次。

耐久降为 0 时，核心进入 `DESTROYED` 状态并停止受到伤害。

### 5.3 核心摧毁后的行为

- 记录 `coreDestroyed = true`。
- 播放核心破碎效果。
- Echo 继续移动和攻击。
- 倒计时继续正常运行。
- 玩家仍需生存到 `00:00`。

若倒计时结束时核心尚未摧毁，则判定本次挑战失败。

## 6. 第三幕管理器

建议使用独立的 `Act3Director` 管理第三幕。

### 主要职责

- 初始化 90 秒倒计时。
- 初始化玩家与初始 Echo。
- 根据剩余时间切换阶段。
- 设置敌人数量和攻击参数。
- 在 00:30 激活时间核心。
- 监听玩家死亡与核心摧毁。
- 在 00:00 统一结算。

### 主要状态

- `remainingTime`：剩余秒数。
- `phase`：当前战斗阶段。
- `isRunning`：是否进行中。
- `playerAlive`：玩家是否存活。
- `coreDestroyed`：核心是否摧毁。

### 相关脚本

| 脚本名称 | 职责 |
|---|---|
| `Act3Director.cs` | 倒计时、阶段切换与结算 |
| `Act3TestEntry.cs` | 从菜单或快捷键直达第三幕 |
| `EchoAIController.cs` | 单个 Echo 的状态机 |
| `EchoPathGenerator.cs` | 随机轨迹生成 |
| `EchoRewindAttack.cs` | 倒带移动与伤害判定 |
| `EchoSpawnDirector.cs` | Echo 数量、生成与补充 |
| `TimeCoreController.cs` | 时间核心受击与摧毁 |
| `Act3UIController.cs` | 计时器、阶段提示和结算界面 |

## 7. 独立测试入口

第三幕应作为可以单独运行的 Unity 场景：

`Assets/Scenes/Act3.unity`

提供以下三种测试方式：

1. **Unity Editor 直接测试**：打开 `Act3.unity`，点击 Play，直接开始第三幕。
2. **主菜单入口**：添加 `TEST ACT III` 按钮，调用场景加载方法，直接进入第三幕。
3. **快捷键入口**：在开发版本中按 `F3`，直接加载第三幕。

测试入口必须跳过第一、二幕的完成条件、录像加载、剧情动画及正常关卡流转。

### 调试初始化

直接进入第三幕时：

- 玩家出生在固定安全点。
- 生命值恢复至第三幕默认值。
- 清空玩家残留的倒带缓存。
- 初始化 Echo 随机生成系统。
- 第三幕时间设置为 `90.0f`。
- 界面立即显示 `01:30`。
- 第一阶段的 Echo 正常生成。
- 时间核心初始隐藏。
- 所有阶段计数、攻击计时器和结算状态重置。

不能依赖第二幕传入的录像、击杀数量或者时间参数。

## 9. 开发优先级

**P0 — 必须完成**

- 第三幕独立场景与调试入口。
- 90 秒倒计时。
- Echo 随机移动、随机倒带。
- 攻击预警与伤害。
- 三阶段敌人数量控制。
- 时间核心与结束判定。

**P1 — 建议完成**

- 不同 Echo 的颜色或轮廓差异。
- 倒带残影、轨迹闪烁和音效。
- 核心受击的全场景反馈。
- 失败与重试界面。

**P2 — 时间充足再考虑**

- 更多随机倒带轨迹形态。
- 更复杂的 Echo 协作攻击。
- 根据玩家表现动态调节难度。

**设计原则：第三幕的难度来自敌我双方使用倒带能力的交锋，而不是要求玩家重新学习新的操作规则。**
