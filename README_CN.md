# REWIND RAMPAGE

> **过去从未真正被抹去。**

**REWIND RAMPAGE** 是一款为 **Ludum Dare 60** 制作的快节奏霓虹风格 2D 动作游戏，灵感来自本届主题 **Old Tech（旧式技术）**。

移动、留下轨迹，再沿着自己的行动路径倒带，以此反击源源不断的追踪者。但这台机器记录的远不止你的求生过程：你留下的每一秒过去，都可能成为必须面对的敌人。

## 游戏介绍

故事发生在一套发生故障的磁带式时间系统中。时间如同老旧录像：可以被录制、倒带和重播，却不一定能够被彻底擦除。

游戏分为三个章节：

### 第一幕 — RECORD（录制）

**生存 90 秒。**

追踪者持续生成，战斗压力逐渐增加。穿越竞技场，留下自己的运动轨迹，利用倒带将移动路线化为攻击。在最后 30 秒里，系统会记录你的行动，为下一幕做好准备。

*计时方式：`00:00 → 01:30`（正计时）。*

### 第二幕 — REWIND（倒带）

**在 30 秒内追杀过去的自己。**

一个幻影将严格重演你在第一幕最后 30 秒的行动。与此同时，弹幕不断朝幻影的位置发射。你必须一边躲避弹幕，一边预测它的行动路线，在自己刚刚经历过的混乱中完成追击。

*计时方式：`00:00 → 00:30`（正计时）。*

### 第三幕 — ERASE（擦除）

**面对那些从未被彻底删除的自己。**

时间档案释放出拥有独立行动能力的残留复制体。与第二幕严格按照录像移动的幻影不同，这些复制体能够自由移动，并发动各自的随机倒带攻击。摧毁时间核心，在清除程序倒计时归零前活下来。

*计时方式：`01:30 → 00:00`（倒计时）。*

## 核心玩法

- **移动并留下轨迹：** 你的移动会在竞技场中留下运动路径。
- **倒带攻击：** 沿着走过的路线高速回溯，将自身的运动轨迹转化为攻击手段。
- **利用轨迹交叉：** 通过交叉轨迹触发强力攻击。
- **对抗自己的历史：** 第一幕的真实操作会在第二幕成为你的对手。
- **从时间档案中生存：** 第三幕的复制体能够自主移动、倒带并攻击你。

## 美术风格与主题

游戏使用深色 2D 网格竞技场、青色运动轨迹、红色追踪者和发光几何特效，并融入老式电子显示设备的视觉语言。

**Old Tech** 不只是画面风格，也是故事设定的一部分：时间系统的运行方式类似一台老化的磁带录像机。由于擦除机制发生故障，那些本应被删除的复制体仍然留在时间档案之中。
