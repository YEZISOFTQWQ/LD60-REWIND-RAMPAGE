# REWIND RAMPAGE

> **The past was never erased.**

[English](README.md) | [简体中文](README_CN.md)

**REWIND RAMPAGE** 是一款为 **Ludum Dare 60（Compo）** 制作的快节奏霓虹风格 2D 动作游戏，灵感来自本届主题 **Old Tech（旧科技）**。

移动、留下轨迹，再沿着自己的历史路径高速倒带，用过去的行动反击不断逼近的追踪者。然而，这台机器记录的不只是你的求生过程：你留下的每一秒，都可能成为之后必须面对的东西。

## 游戏介绍

在一套发生故障、以磁带为基础的时间系统中，时间就像一段老式录像：它可以被录制、倒带和重放，却未必能够被彻底擦除。

游戏包含一个三幕剧情模式，以及不断扩展的无尽挑战模式。

## 剧情模式

### 第一幕 — RECORD（录制）

**生存 90 秒。**

追踪者不断生成，战斗压力持续上升。玩家可以在竞技场中移动、留下自己的轨迹，并利用倒带将行动路径转化为攻击。在最后 30 秒，系统会录制玩家的实际操作，为下一幕做好准备。

*计时器：`00:00 → 01:30`（正计时）。*

### 第二幕 — REWIND（倒带）

**在 30 秒内追杀过去的自己。**

一个幻影会严格重演玩家在第一幕最后 30 秒的操作。玩家需要观察其即将经过的路线、寻找拦截机会，同时躲避朝幻影所在位置发射的弹幕，并在录像结束前将其消灭。

*计时器：`00:00 → 00:30`（正计时）。*

### 第三幕 — ERASE（擦除）

**面对那些从未被真正删除的自己。**

时间档案释放出大量能够独立行动的复制体。开场时，这些幻影同时撞向玩家，使玩家只剩下 **1 HP**。与第二幕中严格按照录像行动的幻影不同，这些复制体能够自由移动，并主动发动自己的倒带攻击。玩家必须摧毁时间核心，并坚持到清除倒计时归零。

*计时器：`01:30 → 00:00`（倒计时）。*

## 无尽模式 — THE TAPE NEVER STOPS

**剧情模式教会你规则，无尽模式则考验你能把这些规则运用到什么程度。**

在无尽模式中，玩家将依次经历高密度追踪弹、覆盖竞技场的危险区域，以及借鉴 MMORPG 高难副本的 Boss 跑机制。场地攻击不只是需要躲避的威胁：它们也可以用来消灭追踪者。

### 倒带整个战场

倒带影响的不只有玩家自身。场地中的时间机制也会沿着已记录的历史同步倒放；当玩家结束倒带后，机制将从回退到的位置继续正向播放，**再次造成伤害**。

同一场爆炸可以重新发生，同一道扫射可以再次经过战场。掌握时机后，玩家就能把危险的机制变成自己的武器。

机制及其所属阶段的时间轴会与玩家同步回滚，因此不能通过倒带跳过尚未处理的攻击。从 P4 开始，无尽 Boss 战的中央生存计时器同样随倒带倒退，避免通过反复回放同一段时间刷取成绩。

### 开场阶段

| Phase | 关卡内容 | 玩法说明 |
| --- | --- | --- |
| **P1 — BULLET STORM** | 30 秒生存 | 在高密度追踪弹中生存，同时完整记录玩家的实际操作。 |
| **P2 — DETONATION** | 可倒带的范围爆炸 | P1 中剩余的追踪弹全部原地停止，显示爆炸范围并引爆。玩家倒回爆炸前的历史状态后，可以让它们再次爆炸。 |
| **P3 — MECHANIC RUSH** | 30 秒机制入门 | 一个不参与攻防的幻影重演 P1 的玩家操作。玩家依次体验 **TRACK LOCK、HEAD SWEEP、BAD SECTORS、OVERWRITE** 四种机制，只有极少量追踪弹干扰。 |

### P4 及之后 — 无尽 Boss 战

从 **P4** 开始，一盘巨大的老式磁带成为 Boss。它受重力影响坠落，落地时引发明显的画面震动，并以沉重的跳跃方式移动。**P4 中，Boss 的起跳和落地不会造成伤害。**

Boss 第一阶段将分别使用 **TRACK LOCK** 和 **HEAD SWEEP**，最后把两种机制组合成一轮连续攻击。只有处理完该阶段的所有机制，才能进入 P5，而不是单纯等待固定时长结束。

**Boss 无法被击败。** 后续阶段将不断扩展战斗机制，并最终从最后一个 Boss Phase 循环回 P4。挑战只有在玩家被击败时才会结束。

*P4 已完成详细技术设计；后续 Boss Phase 与完整的无限循环仍在开发规划中。*

## 核心玩法

- **移动并留下轨迹：** 玩家的移动会在竞技场中留下路径。
- **倒带攻击：** 沿历史路径高速返回，把过去的移动变成进攻手段。
- **利用轨迹交叉：** 通过交叉轨迹触发强力攻击。
- **与过去的自己战斗：** 剧情模式第二幕中，玩家录制的操作会成为新的对手。
- **在时间档案中生存：** 第三幕的复制体能够独立行动和发动倒带攻击。
- **倒带整个战场：** 在无尽模式中重放场地机制，躲避危险或清理追踪者。
- **处理 Boss 跑机制：** 观察预警、寻找安全路线，并反过来利用 Boss 的攻击。

## 美术风格与主题

游戏结合了深色 2D 网格竞技场、青色移动轨迹、红色追踪者、发光几何特效、复古电子数码显示屏以及老式磁带机械结构。

**Old Tech（旧科技）** 不只是视觉装饰，更是整个世界的基础：时间系统像一台老化的磁带录像机一样运作。由于擦除机构故障，那些本该消失的记录依然残留，生成了不应继续存在的复制体。**RECORD、PLAY、REWIND、ERASE** 既是机器的操作状态，也是游戏玩法与故事的一部分。

## 开发进度

**REWIND RAMPAGE 仍在积极开发中。** 移动、追踪弹、倒带与基础视觉系统已经形成可玩的原型。三幕剧情模式和无尽模式的开场阶段已完成设计，正在实现和调整。无尽模式的第一段 Boss 战（P4）已有详细的技术方案；后续循环中的 Boss Phase 尚未最终确定。
