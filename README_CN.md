# REWIND RAMPAGE

> **The past was never erased.**

[English](README.md) | [简体中文](README_CN.md) |  [Release](https://github.com/YEZISOFTQWQ/LD60-REWIND-RAMPAGE/releases)

**REWIND RAMPAGE** 是一款为 **Ludum Dare 60（Compo）** 制作的快节奏霓虹风格 2D 动作游戏，灵感来自本届主题 **Old Tech（旧科技）**。

移动、留下轨迹，再沿着自己的历史路径高速倒带，用过去的行动反击不断逼近的追踪者。然而，这台机器记录的不只是你的求生过程：你留下的每一秒，都可能成为之后必须面对的东西。

## 游戏介绍

在一套发生故障、以磁带为基础的时间系统中，时间就像一段老式录像：它可以被录制、倒带和重放，却未必能够被彻底擦除。

先经历三幕剧情，再进入一场不断升级、永不终结的 Boss 挑战。在这里，你最强大的武器——**倒带时间**——也会被 Boss 反过来用于对付你。

## 剧情模式

### 第一幕 — RECORD（录制）

**生存 90 秒。**

追踪者不断生成，战斗压力持续上升。玩家可以在竞技场中移动、留下自己的轨迹，并利用倒带将历史路径转化为攻击。在最后 30 秒，系统会录制玩家的实际行动，为下一幕做好准备。

*计时器：`00:00 → 01:30`（正计时）。*

### 第二幕 — REWIND（倒带）

**在 30 秒内追杀过去的自己。**

一个幻影会严格重演玩家在第一幕最后 30 秒的行动。玩家需要观察它即将经过的路线，寻找拦截机会，同时躲避朝幻影位置发射的弹幕。这些子弹在发射后沿直线前进，不会继续追踪，因此时机与站位至关重要。幻影接下来的一小段路径会提前显示，帮助玩家规划攻击。

*计时器：`00:00 → 00:30`（正计时）。*

### 第三幕 — ERASE（擦除）

**面对那些从未被真正删除的自己。**

时间档案释放出能够独立行动的复制体。开场时，复制体的集体冲撞会让玩家只剩下 **1 HP**。与第二幕中严格按照录像行动的幻影不同，这些复制体拥有独立的行动能力，并会发动带有预警的倒带攻击。

当倒计时剩余 30 秒时，时间核心出现。玩家必须对核心造成 **3 次有效命中**才能将其摧毁。但破坏核心还不够：玩家仍须生存到清除倒计时归零。最后一击将触发戏剧性的画面定格、镜头特写和核心爆炸，随后战斗继续。

*计时器：`01:30 → 00:00`（倒计时）。*

## 无尽模式 — THE TAPE NEVER STOPS

**剧情模式教会你规则，无尽模式则考验你能把这些规则运用到什么程度。**

在无尽模式中，玩家将依次面对追踪弹、覆盖竞技场的危险区域，以及借鉴 MMORPG 高难副本的 Boss 机制。场地攻击不只是需要躲避的威胁：它们也可以用来消灭追踪者。读懂机制、规划安全路线，再把时间本身变成武器。

### 倒带整个战场

倒带影响的不只有玩家自身。场地中的时间机制也会沿着已记录的历史同步倒放；当玩家结束倒带后，机制将从回退到的位置继续正向播放，**再次造成伤害**。同一场爆炸可以重新发生，同一道扫射可以再次经过战场。

机制在倒放过程中不会造成伤害。机制及其所属阶段的时间轴会与玩家同步回退，因此无法通过倒带直接跳过尚未处理完的攻击。一般情况下，已经消灭的敌人、损失的 HP 和获得的分数不会回滚；P2 有一项特殊规则，允许将爆炸前仍存活的追踪弹恢复到爆炸之前的历史状态。

从 **P4** 开始，Boss 战专属的中央生存计时器从 `00:00.00` 开始计时。正常行动时时间向前，玩家或 Boss 发动倒带时时间**同步倒退**。因此，无法通过反复重放同一段历史来刷取生存时间。

### 开场阶段

| Phase | 关卡内容 | 玩法说明 |
| --- | --- | --- |
| **P1 — BULLET STORM** | 30 秒生存 | 在密集的追踪弹中生存，同时记录玩家的实际行动，供 P3 重放。 |
| **P2 — DETONATION** | 可倒带的集体爆炸 | P1 中剩余的追踪弹原地停止，显示爆炸范围并同时引爆。玩家若倒回足够久，就能恢复它们爆炸前的位置并重演爆炸；在 P2 开始前已被击杀的追踪弹不会复活。 |
| **P3 — MECHANIC RUSH** | 30 秒机制入门 | 一个**纯视觉、不参与攻击与碰撞**的幻影重演玩家在 P1 中的行动。四种场地机制依次登场，只有极少量追踪弹干扰。 |

P3 将介绍贯穿整场 Boss 战的四种机制：

- **TRACK LOCK（引导地火）** — 锁定圈跟随玩家移动，随后锁定一个位置并引爆。
- **HEAD SWEEP（扫射）** — 一道光束扫过竞技场，同时留下可以识别的安全缺口。
- **BAD SECTORS（方格地火）** — 被标记的网格区域依次分波爆炸。
- **OVERWRITE（步进地火）** — 危险区域逐步向前覆盖，并在经过的位置短暂留存。

### P4–P7 — 无尽 Boss 战

从 **P4** 开始，一盘巨大的老式磁带成为 Boss。它落入竞技场，以沉重的动作不断跳跃，并在落地时引发明显的镜头震动。**Boss 的跳跃、落地和本体接触都不造成伤害**；真正的危险来自它发动的场地机制以及不断逼近的追踪弹。

这盘磁带**没有 HP，无法被击败**。P4 至 P7 是同一个连续 Boss 战中的不同攻击阶段，而不是四场独立战斗。只有当前阶段要求的攻击全部真正结束，才会进入下一阶段；并不存在等待固定现实时间即可过关的机制。

| Phase | 名称 | 首轮挑战 |
| --- | --- | --- |
| **P4** | **MAGNETIC IMPACT** | 分别熟悉 **TRACK LOCK** 与 **HEAD SWEEP**，最后处理两种机制真正重叠的组合攻击。 |
| **P5** | **BAD SECTORS + OVERWRITE** | 分别应对 **BAD SECTORS** 与 **OVERWRITE**，再处理两者的组合。 |
| **P6** | **HEAD SWEEP + BAD SECTORS** | 应对 **HEAD SWEEP** 与 **BAD SECTORS**，并完成需要精确规划路线的重叠攻击。 |
| **P7** | **FINAL OVERWRITE** | 连续应对 **TRACK LOCK + BAD SECTORS**、**HEAD SWEEP + OVERWRITE** 及三机制综合攻击，最终挑战 Boss 的 **MEMORY LOCK**。 |

### MEMORY LOCK — REMEMBER.

在 P7 中，Boss 首先以正常预警向玩家展示一段攻击。玩家成功躲过后，磁带将**强制接管控制权并倒带时间**——玩家自身也会沿着刚才实际走过的轨迹向后返回。

强制倒带会回到**首次预警出现之前**，让玩家有时间重新规划走位。随后控制权恢复，**完全相同的攻击将再次发动，但不再提前显示危险区域或安全区提示**。攻击的布局、顺序和时机保持一致：答案已经展示过一次，现在要靠记忆重新完成。

真正发动攻击时，爆炸和扫射效果仍然会正常显示。MEMORY LOCK 不会递归触发自己，也不会恢复玩家已经损失的生命值。

### LOOP 02+ — OVERLOAD LOOP（过载循环）

完成 P7 后，战斗立即回到 P4。磁带 Boss 不会重新生成，中央生存计时器不会清零，挑战持续进行，直到玩家被击败。

从 **LOOP 02** 开始，P4–P7 的所有攻击都变成**复杂机制组合**，不再出现用于教学的单独机制。**每个 Phase 的结尾都有一次 Boss 强制倒带攻击**：先正常显示一组组合机制的预警，再让玩家沿自己的历史路线倒回机制开始之前，最后在没有提前预警的情况下重演同一组组合攻击。

与此同时，**每次刷怪事件**生成的追踪弹数量随循环逐轮变为原来的三倍，最多为**每次 81 枚**：

| Boss 循环 | 每次刷怪事件生成的追踪弹 |
| --- | ---: |
| LOOP 01 | 1 |
| LOOP 02 | 3 |
| LOOP 03 | 9 |
| LOOP 04 | 27 |
| LOOP 05 及以后 | 81 |

**81 只是单次刷怪数量上限，不是竞技场中同时存在的追踪弹数量上限。** 之前生成且尚未消失的追踪弹可以与新一轮追踪弹同时存在。追踪弹的移动速度与伤害也不会随着数量一起乘三。

玩家若跨越 Phase 或 Loop 边界倒带，当前阶段、循环序号、攻击进度以及对应的刷怪倍率都应返回历史中的正确状态。整场 Boss 挑战仍然只有一个终点：玩家被击败。

## 核心玩法

- **移动并留下轨迹：** 玩家真实的移动会在竞技场中留下路径。
- **倒带攻击：** 沿历史路径高速返回，把过去的移动变成攻击手段。
- **利用轨迹交叉：** 历史轨迹相交时可以触发强力爆炸。
- **与过去的自己战斗：** 第二幕中，玩家最后 30 秒的真实行动会成为新的对手。
- **在时间档案中生存：** 第三幕的独立复制体能够自由行动并发动倒带攻击。
- **倒带整个战场：** 在无尽模式中回滚并重演场地攻击，躲避危险或消灭敌人。
- **读懂复杂机制：** 掌握多种高难机制的重叠规律，最终在没有预警的情况下凭记忆再次完成。

## 美术风格与主题

游戏结合了深色 2D 网格竞技场、青色移动轨迹、红色追踪者、发光几何特效、复古电子数码显示屏以及老式磁带机械结构。

**Old Tech（旧科技）** 不只是视觉装饰，更是整个世界的基础：时间系统像一台老化的磁带录像机一样运作。由于擦除机构故障，那些本该消失的记录依然残留，生成了不应继续存在的复制体。**RECORD、PLAY、REWIND、ERASE** 既是机器的操作状态，也是游戏玩法与故事的一部分。
